# Claude Camp Week 2 Python Assignments

This repository contains my Week 2 Python practice assignments for Claude Camp.  
The focus is on beginner Python programming, including user input, loops, dictionaries, lists, JSON file handling, and exception handling.

## Assignments Included

### 1. Word Frequency Counter

File: `word_frequency_counter.py`

This program:
- accepts a block of text from the user
- ignores uppercase and lowercase differences
- counts how many times each word appears
- stores the results in a dictionary
- sorts the output by frequency

### 2. Student Roster

File: `student_roster.py`

This program practices working with student data and Python data structures.

### 3. Todo List Manager

Files:
- `todos.py`
- `todos.json`

This program:
- adds todo tasks
- deletes tasks
- marks tasks as done
- saves tasks to a local JSON file
- loads previous tasks when the program restarts
- handles missing files without crashing

### 4. Safe Calculator

File: `safe_calculator.py`

This program:
- supports addition, subtraction, multiplication, and division
- handles division by zero safely
- handles non-numeric input safely
- exits gracefully when the user types `quit` or `exit`

## Skills Practiced

- Python functions
- `while` loops
- `if / elif / else`
- lists and dictionaries
- JSON file saving and loading
- `try / except` exception handling
- Git and GitHub workflow
